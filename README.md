# Contour Lab

A dependency-free, responsive generative contour-poster editor. Adjust the
controls on the left and see the canvas update instantly on the right.

## Features

- Control line count, spread, center, bend, and rotation
- Customize background, contour, and signature colors
- Add animated dots, then pause or resume their motion
- Edit or hide the poster signature
- Export the finished design as an 878 × 1180 PNG or editable SVG
- Responsive layout with no framework or build step

## Live site

[Open Contour Lab](https://cupojoseph.github.io/contour-lab/)

## Run locally

Open `index.html` directly in a browser, or serve this directory locally:

```bash
python3 -m http.server 4173
```

Then open [http://localhost:4173](http://localhost:4173).
